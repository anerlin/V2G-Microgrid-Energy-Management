# V2G-Microgrid-Energy-Management
Overview
This project implements a Vehicle-to-Grid scheduling optimization model for microgrid energy management, integrating EVs, buildings, and data centers.
Paper Reference
Based on: "Online Joint Ride-Sharing and Dynamic Vehicle-to-Grid Coordination for Connected Electric Vehicle System"
Key Innovations Implemented
Online bilevel optimization
Benders decomposition for MILP problems
Communication uncertainty modeling
Battery degradation penalty
